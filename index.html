HealthDCAT-KR은 대한민국 보건의료데이터 중개 포털(이하 중개포털)에서 제공하는 데이터세트를 의미적으로 일관되게 기술하기 위한 DCAT 응용 프로파일이다. RDF 기반 메타데이터 어휘를 이용하여 데이터 카탈로그와 데이터세트를 기술하기 위한 메타데이터 요소를 필수요소와 권장요소로 정의한다. 또한 DCAT-AP 기반 대한민국 메타데이터 표준과 HealthDCAT-AP를 기반으로 서로 다른 데이터 포털에서 사용되는 메타데이터를 공통 메타데이터 요소로 표현함으로써 데이터세트 간 상호운용성을 지원한다. 본 설명서의 각 속성 요구 수준은 중개포털 기준으로 표기한다.

HealthDCAT-KR defines the RDF vocabulary of a DCAT application profile for the Korean Healthcare Data Portal. It specifies mandatory and recommended metadata elements for data catalogs and datasets. Based on the Korean National Metadata Standard and HealthDCAT-AP, it establishes a common metadata model across heterogeneous data portals, thereby supporting dataset interoperability and enabling integrated discovery and reuse. This specification defines the requirement level of each property for the Korean Health Data Brokerage Portal.

이 문서는 초안이며 내용은 변경될 수 있다.

Introduction

대한민국의 보건의료 데이터 중개 포털을 위한 HealthDCAT 응용 프로파일(이하 HealthDCAT-KR)은 보건의료데이터 중개 포털에서 제공하는 보건의료 데이터셋을 기술하기 위한 메타데이터 명세(metadata specification)이다. HealthDCAT-KR은 「데이터 카탈로그 표준가이드」를 기반으로 HealthDCAT-AP의 보건의료 특화 속성을 반영하여 국가 데이터 통합플랫폼(One-윈도우) 및 유럽연합의 보건의료 데이터 2차 활용 플랫폼(가칭 HealthData@EU)과의 연계성을 고려해 확장한 응용 프로파일이다. 적용 대상은 공공기관, 의료기관, 연구기관 등이 생산 또는 관리하는 보건의료 데이터 중 연구 활용 가치가 있는 데이터셋으로, 이를 통합 검색하고 연계·활용할 수 있도록 기술하는 것을 목적으로 한다.

모델링 원칙

HealthDCAT-KR은 국제 표준인 DCAT 3을 기반으로 대한민국 국가 메타데이터 표준과 HealthDCAT-AP를 반영하여 구성하였으며, 보건의료 데이터의 검색·연계·활용을 지원하기 위해 필요한 최소의 어휘만을 신규로 정의한다. 구체적인 모델링 원칙은 다음과 같다.

  • HealthDCAT-KR은 기존 RDF 어휘의 재사용을 원칙으로 하며, 특히 더블린코어 메타데이터 어휘(DCMI Metadata Terms)를 광범위하게 재사용한다. 예를 들어 제목, 최초 발행일, 최근 수정일은 dct:title, dct:issued, dct:modified로 표현한다.
  • HealthDCAT-KR은 국가 데이터 통합플랫폼 연계를 위해 국가 표준 항목을 준용하고, ndi:viewCnt·ndi:downloadCnt·ndi:pltfrmAccessToken·ndi:srvcType 등 국가 데이터 표준 확장 속성을 필수 속성으로 채택한다.
  • HealthDCAT-KR은 사실상 국제 표준으로 부상 중인 HealthDCAT-AP를 기반으로 향후 국제 연계·교류 시 상호운용성을 확보하도록 설계하되, 중개 포털에서 검색 가능한 데이터가 '제한'·'공개' 권한에 해당하므로 HealthDCAT-AP의 '제한(Restricted)' 권한 필수 항목을 준용한다.
  • HealthDCAT-KR은 DCAT-AP 모델링 원칙에 따라 필수(mandatory)·권장(recommended) 속성을 정의한다. 필수 속성은 데이터세트 기술을 위해 반드시 사용해야 하고, 권장 속성은 정보가 제공될 경우 사용을 권고할 수 있는 속성이다.

HealthData DCAT-AP의 온톨로지 모델

HealthData DCAT-AP의 핵심 클래스는 DCAT과 동일하다. 데이터 카탈로그(dcat:Catalog) 클래스는 데이터세트 또는 데이터 서비스의 집합이다. 이 클래스는 데이터세트(dcat:Dataset) 클래스와 데이터 서비스(dcat:DataService) 클래스를 각각 dcat:dataset와 dcat:service 속성으로 연결한다. 데이터세트(dcat:Dataset)는 다양한 형식으로 접근하거나 다운로드 받을 수 있는 데이터의 집합이다. 데이터세트는 하나 이상의 배포 형식(dcat:Distribution)으로 표현된다. 데이터세트의 특정한 배포 형식(dcat:Distribution)은 물리적인 데이터세트를 의미하며, CSV, XLSX와 같이 특정한 파일 형태로 다운로드 받을 수 있다. 데이터세트의 배포 형식은 API와 같은 데이터 서비스(dcat:DataService) 형태로 표현된다.
